# 韭菜模拟器 LeekSim

回到过去任何一个交易日，时钟从那天的开盘开始走。你**只能看到那一刻之前的行情**，后面的 K 线一根都不会提前出现。买入、卖出、做空、上杠杆 —— 最后告诉你：**你跑赢了躺平不动的人吗？**

线上地址：https://littler999.github.io/leek-sim/

## 怎么玩

1. 搜索标的（输入代码或公司名，如 `NVDA` / `Apple`）—— 已收录 **327 只**美股与 ETF，数据按标的懒加载（单个约 120KB）
2. 选起始日期、初始资金、杠杆
2. 进入终端，K 线开始跳动。速度档：**实时**（1 根 K 线=60 秒，和真盯盘一样）/ **10×**（默认，1 根=6 秒）/ 60× / 300× / 1800×（13 秒走完一天）
3. **图表**：支持 `分时 / 5分 / 15分 / 60分 / 日K / 周K / 月K / 年K`；滚轮或双指缩放、拖拽左右平移（**右边界永远停在当前时刻，未来是空白**）、双击复位跟随；图上会画出你的**持仓成本线**与**买卖点**
4. 随时下单（买入 / 卖出 / 做空 / 平仓），或者跳过时间（+1日 / +1周 / +1月 / +1年）
4. 点「结算」→ 输出**韭菜指数**：你的收益 vs 买入持有（α）、最大回撤、卖飞/追高次数
5. 点「看看后来发生了什么」→ 揭示完整走势 + 你每一笔买卖的位置（当时你不可能看到）

## 数据真实性（诚实声明）

| 部分 | 真实性 |
|---|---|
| 日线（开高低收、成交量） | **100% 真实**，来自 Nasdaq 官方公开接口，2016-09-15 → 至今，覆盖美股/ETF 约 300 只（按市值排序） |
| 判定（韭菜指数 / α / 回撤） | **只依赖日线收盘价，100% 真实** |
| 当日 1 分钟 K 线 | 由算法按当日**真实开高低收**生成（界面标注「分时合成」），形态逼真但非真实逐笔。**免费渠道确实拿不到历史分钟数据**（已实测：Nasdaq 盘中接口只有"今天"；历史接口忽略 interval 参数；Yahoo 只给最近 7 天且对本网络封锁）。想要真实分钟线：Alpaca 免费 key（约 5 年 1m）/ Tiingo IEX / Polygon $29/月（5 年分钟级） |
| 分红 | **未包含**（价格收益口径）。注意：你和对账基准「躺平」都用同一价格序列，所以**比较是公平的**，只是绝对收益比含分红的真实持仓略低（SPY 约 1.3%/年） |

已验证的校准点：QQQ 2021-11-19 收盘 **403.99**（与 SEC 备案文件一致）、SPY 2022-01-03 收盘 **477.71**。

## 本机运行

```bash
cd leek-sim
python3 -m http.server 8000
# 打开 http://localhost:8000
```

URL 参数：`?auto=1&sym=QQQ&date=2020-01-02&cap=10000&lev=1`

## 韭菜指数

```
α = 你的收益率 − 买入持有收益率
指数 = 45×跑输度 + 20×换手频率 + 20×卖飞率 + 15×追高率（0~100）
爆仓 → 直接 100 分
```

等级：🥷镰刀 → 😴躺平大师 → 🙂老手 → 🌱正常人类 → 🥬小韭菜 → 🧄韭菜盒子
