## 一、一句话定义

**回到过去任何一个交易日，只给你当时能看到的数据，让你用真金白银（模拟）做决定——最后用"你跑赢了躺平不动吗"来鉴定你是不是韭菜。**

它不是模拟盘（模拟盘是"预测未来"），它是**时光机 + 信息牢笼**：
你的优势是"知道后来发生了什么"，但产品**强制剥夺**这个优势——屏幕上永远不会出现当前日期之后的一根 K 线。

## 二、我理解的三个产品内核

### 内核 1：剥夺上帝视角（这是灵魂，不是功能）
每个人都说过"我要是 2013 年买了比特币/2020 年 3 月抄底 QQQ 就好了"。但真相是：**你就算回到了那天，你也不敢买**——因为那天满屏都是"流动性危机""史上第 N 次熔断"，你不知道那是底。

产品要还原的正是这种**当时的恐惧**。这一刻的"我去，原来我当年真的会割肉在地板上"，是全部的传播价值。

### 内核 2：跳过按钮 = 人性照妖镜
"跳过 1 年"这个按钮是整个产品最狠的设计。
- 你敢不敢点了买入，然后跳过一年不看？
- 还是你会每天盯着、跌 3% 就手痒卖出？

**操作频率本身就是策略的一部分**，而大多数人一旦能操作，就一定会操作——然后跑输躺平。这是行为金融学里最稳的结论，我们要把它做成可感知的体验。

### 内核 3：跑赢"什么都不做"才是及格线
评判标准不是"你赚了没有"（牛市里猪都能赚），而是**你跑赢了买入持有吗**。
这是专业和业余的分水岭，也是"韭菜"的严格定义：**付出了大量时间、情绪和手续费，最后还不如躺平的人。**

## 三、目标用户与场景

| 用户 | 场景 | 他要的东西 |
|---|---|---|
| 有几年股龄、自认有点本事的散户 | 想证明"我的策略是对的" | 一个能打脸或正名的尺子 |
| 想入场但怕被割的新手 | 想低成本体验"真到崩盘我会怎样" | 恐惧教育 + 心理预演 |
| 纯路人/社交媒体用户 | 被"我是韭菜盒子"的分享卡勾进来 | 好玩、能晒、有谈资 |
| 量化/策略爱好者 | 想快速验证一个简单择时规则 | 可复现的回测游乐场 |

**传播钩子**：固定种子的"同一局挑战"——你玩的是 2008-09-15 起的一局，把链接甩给朋友，他玩的是**同一局**，比谁的韭菜指数低。零后端即可实现（种子写在 URL 里）。

## 四、核心玩法闭环（5 步）

```
① 开局设定  →  ② 今天（信息牢笼）  →  ③ 下注 / 跳过  →  ④ 结算  →  ⑤ 复盘处刑
     ↑                                                                    ↓
     └──────────────────────── 再玩一局 ←──────────────────────────────┘
```

### ① 开局设定
- **模式**
  - `随机穿越`（推荐默认）：系统随机给一个起始日期 + 随机标的，你事前不知道会撞上哪段历史
  - `自选穿越`：你指定日期与标的（如"2008-09-15 雷曼破产日，SPY"）
  - `朋友挑战`：带 seed 的链接，复刻同一局
- **本金**：默认 $10,000（可选 1k / 10k / 100k）
- **标的**：见第八节"标的池"

### ② 今天（信息牢笼）
顶部信息条：`日期 · 标的 · 现价 · 持仓 · 现金 · 总资产 · 浮盈亏`

主视图两块：
- **日 K 图**（默认近 1 年，可切 3 年/全部已解锁历史）——**右侧必然留白**，未来不渲染
- **当日分时图**（分秒级波动，见第六节数据方案）

> ⚠️ 灵魂约束：任何时刻，图表、数值、DOM 里都**不得**出现当前日期之后的数据。

### ③ 下注 / 跳过
- **交易**：买入 / 卖出（数量：1 股 / 1/4 仓 / 半仓 / 全仓 / 自定义）
- **跳过**：
  - `+1 天` `+1 周` `+1 月` `+1 年` `直接跳到今天`
  - 跳跃期间**中间路径被隐藏**，只显示起止两个点，盈亏按终点价结算
  - 这是核心张力：敢不敢不看？

### ④ 结算
- 主动点"结算"，或跳到今天自动结算
- 输出：**韭菜指数 + 等级 + 吐槽 + 分享卡**

### ⑤ 复盘处刑（这是 aha 时刻）
结算后**解除信息牢笼**，把完整曲线铺开：
- 你每一笔买/卖的位置用箭头标出来
- 叠加两条基准线：**买入持有**、**每月定投**
- 高亮三个"最痛时刻"：卖飞的那一笔、追高的那一笔、最大回撤那一段
- 一句处刑文案，例如：
  > "你在 2020-03-16 割肉了。那天是此后十年的最低点。你卖出的位置，比你的买入点低了 34%。"

## 五、关键机制设计

### 5.1 信息遮蔽（最高优先级）
| 要求 | 说明 |
|---|---|
| 图表 | X 轴只渲染到当前日期，右侧留白（留白区画一个淡淡的 🔒 或"未来未解锁"） |
| 数值 | 总资产/浮盈只按当前日期价格计算 |
| 数据加载 | 数据按年分片，客户端只加载"已到达"的年份，增加偷看成本 |
| 诚实声明 | 纯前端方案下，懂技术的用户开 F12 仍能看到数据文件。**这是自我诚实测试，不防君子防不住黑客**；v2 若上后端可按日期下发彻底解决。产品内要在第一次进入时明说这一点。 |

### 5.2 时间跳跃
- 跳跃 = 连续推进 N 个交易日，中间不渲染细节
- 跳跃前弹一个极简确认："跳过 1 年期间你不能操作，确定？"（不要打断节奏，一个小 toast 即可）
- 跳跃后显示一个"这一年发生了什么"的简短结果卡：起止价、你的资产变化

### 5.3 交易规则（默认，可调）
| 项 | 默认值 | 理由 |
|---|---|---|
| 手续费 | $0（美股主流免佣） | 降低认知负担 |
| 滑点 | 0.03% | 保留一点真实感 |
| 分红 | 使用**复权价**自动处理 | 避免"分红凭空蒸发"导致收益率失真 |
| 拆股 | 复权数据已处理 | AAPL 2020 拆 4:1 若不复权会出现 -75% 假暴跌 |
| T+0 | 允许日内回转 | 美股 ETF 现实规则 |
| 做空 | **开放**（卖空开仓 / 买回平仓，需保证金） | D3 已拍板 |
| 杠杆 | 可选 **1x / 2x，默认 1x** | D3 已拍板；默认 1x 以保护核心命题 |
| 保证金 / 强平 | 维持保证金率 **30%**，触及即强制平仓并结束本局 | 见 5.4 |
| 融券费 / 利息 | v1 忽略，假设随时可借 | UI 需注明"未计融券成本" |
| 最小单位 | 1 股（不开放碎股） | 简化，也符合"那时候"的直觉 |

> 📌 复权口径必须统一并展示：图表与收益计算一律用 **Adjusted Close**，UI 上标注"价格已复权（含分红与拆股）"，否则用户会拿复权价跟记忆里的真实价格对不上而质疑产品。

### 5.4 保证金与强平规则（做空 / 2 倍杠杆，D3 衍生）

**账户模型**
- 权益 `E` = 现金 + 持仓市值 − 借款（做空时：现金 − 空头市值）
- 保证金率 `m = E ÷ 持仓名义市值`，维持线 **30%**，触及即强平，本局结束

**爆仓阈值（本金 $10,000，已核算）**

| 场景 | 名义仓位 | 负债 | 触发强平的价格变动 |
|---|---|---|---|
| 2x 做多 | $20,000 | 借入 $10,000 | **下跌 28.6%** 爆仓 |
| 2x 做空 | 空 $20,000 | 保证金 $10,000 | **上涨 15.4%** 爆仓 |

> 做空的爆仓阈值更严苛（15.4% vs 28.6%），因为空头市值随上涨同步膨胀。这是真实的、也是很好的教学点。

**UI 必显（天然紧张感来源）**
- 实时显示「保证金率 42% · 距强平还有 8.3%」
- 图表上画一条**爆仓价横线**（做多画在下方，做空画在上方）
- 保证金率 < 40% 转黄，< 30% 转红

**强平后**
- 权益按强平价结算，**不允许为负**（跳空穿仓时直接归零）
- 本局直接结束，韭菜指数**顶格 100 分**，专属文案：
  > "你爆仓了。2 倍杠杆在下跌 28.6% 时把你清零 —— 而躺平不动的人现在还赚着钱。"

### 5.5 起始日期与随机
- 随机模式下用 seed 生成起始日（范围：标的可交易首日 ~ 今天往前 2 年，保证至少有 2 年可玩）
- seed 写进 URL：`?seed=8f3a2b`，朋友打开得到完全同一局

## 六、数据方案（**最大约束，必须先看这一节**）

### 6.1 已核实的事实（2026-09 检索）

| 数据源 | 免费额度 | 分钟/秒级历史 | 备注 |
|---|---|---|---|
| Yahoo Finance（yfinance） | 日线 **50+ 年**，无限量（非官方） | 1m 仅**最近 7 天**；5m/15m 60 天；1h 730 天 | ToS 限个人使用；自动复权 |
| Tiingo | 日线 **30 年**，1000 次/天 | IEX 盘中（有限） | 免费档限个人/内部使用 |
| Alpha Vantage | 日线 full；1m 有 | 25 次/天（免费） | 额度太小 |
| Polygon.io | 免费仅 **2 年** | Starter $29 → 5 年 + 分钟级；**Developer $79 → 10 年 + 秒级**；**Advanced $199 → 20+ 年 + tick 级** | 商业使用需对应授权 |

**结论：你要的"30 年 + 分秒级"在免费世界里不存在。**

### 6.2 三个可选方案

| 方案 | 覆盖 | 分时粒度 | 成本 | 后端 | 评价 |
|---|---|---|---|---|---|
| **A. 纯静态 · 日线真实 + 分时合成** | 30 年日线（真实） | 分时用**布朗桥**按当日 O/H/L/C 生成（约 390 根/日，可插值到秒） | **¥0** | 不需要 | ✅ 推荐起步：天、周、月、年跳跃全部真实；分时"看起来"真实但**本质是模拟** |
| **B. 静态 + 精选真实分时** | 30 年日线 + **约 20 个"史诗日"真实 1 分钟数据**（1987 黑色星期一、2008-10-13、2020-03-16/23、2021-01-28 GME 等） | 这些日子真实、其余合成 | ¥0 + 少量抓取工作量 | 不需要 | ✅ 体验更好，但覆盖面有限 |
| **C. 接付费数据源（真·分秒级）** | Polygon 10~20+ 年 | 真实秒级 / tick | **$79~199/月** | **需要**（key 不能放前端） | ⚠️ 破坏"零成本纯静态"设定，且要付月费；建议验证需求后再上 |

### 6.3 关于"合成分时"的诚实处理（重要）
如果走方案 A/B，非史诗日的分时是**算法生成的**，必须：
1. 在 UI 上明确标注：`分时走势为按当日 OHLC 生成的教学模拟，非真实逐笔`
2. 用它做日内交易得到的收益**不作为真实策略结论**，产品内要说明
3. 判定韭菜指数的核心指标（跑赢买入持有）**只依赖日线收盘价**，这部分是 100% 真实的

> 我倾向：**日线真实做骨架（决定胜负判定），分时用合成做体感（决定爽不爽）**。这样"结论可信"和"看着爽"两头都不丢。

### 6.4 数据体积估算（方案 A）
- 30 年 ≈ 7,500 个交易日/标的
- 紧凑 CSV（date,o,h,l,c,v；价格定点两位小数）≈ **300 KB/标的**
- 10 个标的 ≈ 3 MB（gzip 后约 1 MB），按标的懒加载，首屏只下 1 个
- ✅ GitHub Pages 完全扛得住

## 七、韭菜指数算法（提案，可推翻）

### 7.1 三个基准
- `R_you`：你的总收益率
- `R_hold`：**买入持有**（开局首日全仓买入，持有到结算日）
- `R_dca`：**每月定投**（每月首个交易日等额买入）

`α = R_you − R_hold`（百分点）——**这是主裁判**

### 7.2 四个行为指标
| 指标 | 定义 |
|---|---|
| 跑输度 | `max(0, −α)`，跑输买入持有多少个百分点 |
| 换手强度 `T` | `交易次数 ÷ max(1, 经历交易日 ÷ 20)`（平均 20 天一次 = 1.0） |
| 卖飞率 `S` | 卖出后 60 个交易日内最高价比卖出价高 ≥10% 的次数 ÷ 卖出总次数 |
| 追高率 `B` | 买入后 60 个交易日内最低价跌破买入价 ≥10% 的次数 ÷ 买入总次数 |

### 7.3 公式
```
LeekScore = clamp(0, 100,
     45 × clamp(0,1, max(0, −α) / 30)   // 跑输 30 个百分点 → 该项满分
   + 20 × clamp(0,1, T)                 // 越频繁越韭菜
   + 20 × S                             // 卖飞
   + 15 × B                             // 追高
)
// 保护条款：若 α ≥ 20 个百分点，最终分强制 ≤ 25
// （真跑赢这么多的，不能算韭菜——频繁交易但赚钱的人只扣行为分）
```

### 7.4 等级与文案
| 分数 | 等级 | 文案方向 |
|---|---|---|
| 0–20 | 🥷 镰刀 | "你才是来收割的。建议开班。" |
| 21–40 | 🙂 老手 | "能管住手，已经赢过 80% 的人" |
| 41–60 | 🌱 正常人类 | "正常水平。你的操作基本被手续费和情绪抵消了" |
| 61–80 | 🥬 小韭菜 | "忙活半天，不如躺平" |
| 81–100 | 🧄 韭菜盒子 | "韭菜中的韭菜。你卖在了最低点，还买了最高点" |

报告里必须列出**最痛的三笔**：卖飞最狠的一笔、追高最狠的一笔、最大回撤区间。

### 7.5 杠杆与做空下的指数修正（D3 衍生）
- **基准不随杠杆改变**：无论玩家开几倍，主基准一律是 **1x 做多买入持有**。用杠杆跑赢不算本事 —— 报告里要额外给一行"若同杠杆躺平"的对照收益，让杠杆的真实代价可见。
- **爆仓**：直接判定 **LeekScore = 100**，覆盖公式计算（见 5.4）。
- **纯做空 / 以做空为主**：把主基准换成"同期持有 SPY 不动"，因为此时"买入持有该标的"不是可比动作。α 统一改用**策略净值 vs 基准净值**计算。

## 八、标的池（D2：可搜索）

用户可从预置池中搜索并选择标的，**不是固定几只**。

### 8.1 预置池分组（首批建议 40~60 只）

| 分组 | 代表标的 | 数据起点（需注意） | 作用 |
|---|---|---|---|
| 宽基 ETF | SPY、QQQ、IWM、DIA、VTI | SPY 1993 / **QQQ 1999-03-10** / VTI 2001 | 主力玩法，波动温和，样本期长 |
| 科技巨头 | AAPL、MSFT、NVDA、GOOGL、AMZN、META | AAPL 1980 / NVDA 1999 / META 2012 | 高成长，含拆股（复权考验） |
| 高波动 / 妖股 | TSLA、GME、COIN、PLTR、AMD | TSLA 2010 / GME 2002 / COIN 2021 | 刺激，但样本期短 |
| 非股资产 | TLT（长债）、GLD（黄金）、VNQ | TLT 2002 / GLD 2004 | 测资产配置与对冲 |
| **反面教材（必选）** | CSCO、INTC、ARKK、XLE | CSCO 1990 / ARKK 2014 | **对冲幸存者偏差**，见 8.3 |

### 8.2 体积与加载策略
- 每只 30 年日线 ≈ 7,500 行 ≈ **300 KB**（CSV，价格定点两位小数）
- 50 只 ≈ 15 MB（gzip ≈ 5 MB）——**不能全量首屏加载**
- 策略：`data/<SYMBOL>.csv` 按需懒加载，首次选中才下载，已加载的缓存在内存
- 首屏默认只加载 SPY（300 KB，gzip 后约 90 KB）

### 8.3 幸存者偏差对冲（重要）
可搜索池若只放"活下来的赢家"，用户会得出"买啥都涨"的错觉，产品结论就废了。
**必须包含"活下来但没涨"的标的**：CSCO（2000 年高点至今未回本）、INTC、ARKK（2021 高点腰斩）、XLE。
复盘页需注明："本池只包含存续至今的标的，退市公司不在其中 —— 真实市场的坑比这更深。"

### 8.4 已核实的价格事实（用于校准与验收）
- QQQ 数据**始于 1999-03-10**；当前（2026-09）约 **$714**，历史最高收盘 **$745.34**（2026-06-02）
- 你所举的"200 → 400"大致对应 **2020 年中 → 2021 年底**（QQQ 2020 年开盘约 $206，2021 年内最高触及 $403.99）
- 所以"回到 1996"这个 30 年窗口 **对 QQQ 不成立**，只有 SPY 等少数标的可回到 30 年前
- → **约束：随机穿越时必须按该标的数据起点裁剪可选日期范围**，不能让用户抽到无数据的日期

## 十一、验收标准（可测）

| # | 项 | 判据 |
|---|---|---|
| A1 | 数据完整性 | 每标的 30 年日线，交易日无缺失；随机抽查 10 天与公开源一致（允许复权口径差异，需说明） |
| A2 | 复权正确 | QQQ 2020-07 → 2021-11 涨幅应约 **+95%**（约 $200 → $400 量级）；AAPL 2020-08 拆股处不得出现单日 -75% |
| A3 | 信息遮蔽 | 当前日期之后的数据：图表中不渲染、DOM 中不存在（可脚本抽查） |
| A4 | 跳跃正确 | 点"+1年"，日期 = 起始日 + 1 年（取下一个交易日）；资产按终点收盘价结算，与手算一致 |
| A5 | 交易正确 | 买入/卖出后 现金+持仓市值 = 总资产；含滑点；不允许透支/超卖 |
| A6 | 指数可复现 | 固定回放脚本：① 全程不操作 → 韭菜指数应 ≤ 20（因为等同于买入持有，但空仓则不成立，需明确"不操作=空仓"≠"买入持有"）② 每日随机买卖 → 指数应 ≥ 60 |
| A7 | 分享可复现 | 同 seed 的两台设备得到完全相同的起始日、标的与价格序列 |
| A8 | 双端 | 390×844 / 1440×900 无横向滚动、0 console error、按钮 ≥44px |
| A9 | 零外部依赖（方案 A/B） | 无运行时 CDN/字体/图片请求 |

> A6 需要特别设计：**"什么都不做"= 空仓 = 收益 0**，而买入持有是基准。所以"不操作"的人如果标的涨了，他会跑输基准 → 分数不低。这是对的（踏空也是韭菜行为的一种），但要在文案里解释清楚，否则用户会困惑"我啥也没干凭啥是韭菜"。

## 十二、风险与诚实声明

| 风险 | 说明 | 应对 |
|---|---|---|
| **R1 数据 ToS** | Yahoo/Tiingo 免费档限"个人/内部使用"，公开商用有合规风险 | 上线前确认；或改用明确允许再分发的数据源；或只取"公开事实性历史价格"并注明来源 |

| **R5 结论被误用** | 有人拿它当真实回测去投真钱 | 页脚免责声明：教育娱乐用途，不构成投资建议 |
